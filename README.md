# the-expanse-map - Интерактивная карта Солнечной системы.

Веб-приложение, визуализирующее Солнечную систему из вселенной The Expanse.  
Планеты, спутники, астероиды и орбитальные станции движутся по реальным орбитам с настоящими периодами.  
Включает таймер, масштабирование, слежение за объектами и информационные карточки.

## ✨ Возможности

- Реалистичные орбиты планет и спутников (решение уравнения Кеплера)
- Пояс астероидов с вращением
- Орбитальные станции (Верфи Буша, Тихо, и др.)
- Таймер игрового времени со стартом 2350.01.01
- Ускорение времени (минута/час/день за секунду. Функция по умолчанию отключена.)
- Слежение за планетой при клике
- Информационные карточки с описанием и ссылками
- Сохранение состояния (позиция камеры, время, слежение) в localStorage
- Адаптивность для ПК и мобильных устройств

## 🎮 Управление

| Действие | Способ |
|----------|--------|
| Перемещение камеры | Перетаскивание мышью / одним пальцем |
| Приближение/отдаление | Колёсико мыши / щипок двумя пальцами |
| Выбор объекта | Клик / тап по планете или спутнику |
| Открыть описание | Клик по объекту (не все планеты имеют описание) |
| Перейти по ссылке | Кнопка «Перейти в локацию» в меню |
| Ускорение времени | Отключено для обычных пользователей (можно включить в коде) |

## 🚀 Запуск

Просто откройте `index.html` в браузере или используйте [GitHub Pages](https://your-username.github.io/your-repo).

Локально можно запустить через любой статический сервер, например:

python -m http.server 8000


Затем откройте http://localhost:8000.

➕ Как добавить свою планету или спутник
Все объекты находятся в массиве CONFIG.planetData в файле index.html.
Пример добавления планеты:
```javascript
{
    name: "Neptune",
    nameRu: "Нептун",
    a: 30.07 * 214.8,          // большая полуось в мировых единицах
    e: 0.0086,
    peri: 44.9 * Math.PI / 180,
    radius: 3.8,
    color: "#4169e1",
    angle: 0,
    periodDays: 60182,
    description: "Описание...",
    link: "https://example.com",
    satellites: [ ... ]
}
```
Для спутников используйте aWorld (расстояние в мировых единицах) и periodDays (реальный орбитальный период в днях).
